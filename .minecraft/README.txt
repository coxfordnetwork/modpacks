====================================================
Beta 1.7.3 Nostalgia Patch


Compiled by /u/m4_semperfi


MultiMC / Multiplayer Compatible (Mostly)
====================================================

A modpack that builds upon Beta 1.7.3 with various bug fixes & improvements, with a few creative choices here and there. Modpack is heavily vanilla oriented, so players that want a realistic, nostalgic, and Beta feel will love this.

Optionally, you can enable Alpha world generation & the Alpha texture pack to enjoy the "Alpha experience" but with all the new features of Beta.

===============================
INSTALLATION / IMPORTANT NOTES
===============================
* Drag & drop .zip file onto MultiMC interface, give it a minute to load and add the instance

That's it! But before you start:

* Edit instance, and either enable "Raw Fixes" or "Raw Fixes (Alpha Generation)" - depending on if you want Beta gen or Alpha gen
* On servers, "ToolEffectivenessFix" causes some issues if you try to mine certain blocks with certain tools (An axe & crafting table, for example)
* You can easily uncheck SinglePlayerCommands if you do not want it and Optifine if it is causing you issues
* If using a Texture Pack with Optifine double check water/lava animations are on "Dynamic" to prevent them visually glitching

Want to use a desktop shortcut with the old icon?

* Right click on desktop, create shortcut
* Enter this (make sure to modify it depending on where you installed MultiMC):

C:\Users\NAME\THEN\PATH\TO\MultiMC\MultiMC.exe -l "Beta 1.7.3 - Nostalgia Patch"

* Right click icon, click properties
* Click change icon, navigate to where the MultiMC Nostalgia Patch instance .minecraft is, and you should be able to select MC.ico
Done!

=================
Creative Choices
=================
* Tall grass removed   (by SnowshoeIceboot)
	-Purely for aesthetic reasons, in my opinion it looks better and feels more nostalgic. Wheat seeds are obtained from dirt like before.
* Ravine caves added from Beta 1.8   (by SnowshoeIceboot)
	-I think this generation blends right in with the Beta cave system, especially with all the old textures, ores, sounds, and cave generation.
	-There are no mineshafts/1.8+ type caves so don't worry about it feeling like modern day Minecraft.
* BetterTemperatures   (by @ggggaaaannnngggg#4471)
	-Deserts and rain forests are generated slightly larger. Biome blending is more smooth, you won't run into a super tiny desert, other biome temperatures unaffected.
	-Ice desert biome added. These were in the Beta code, but never utilized: a desert but with snow.
* (Optional) Alpha generation (by @Logan#9337), this also comes with the option to turn off leaf color variation and to turn off beds (by @ggggaaaannnngggg#4471)
* (Optional) Craftable chainmail armor using chain links crafted from an iron ingot. Better than leather armor but worse than iron armor.
* (Optional) Craftable colored armor using wool, basically the same function as modern colored leather armor.
* (Optional) Winter Mode, map is fully covered in snow.

Texture Packs
==============
* AlphaTextures
	-All Alpha textures including bright grass [Excluding diamond/gold/iron blocks due to terrain.png changes and limitations in b1.7.3]

	-All vanilla textures upgraded to 32x resolution in higher detail than 16x

* Faithful32packPvP (Almost all textures by Vattic)
	-The same texture pack but with low fire, ore outlines, clear glass, and clear GUI/hotbar for enhanced surviving/PvPing

* OldCobble1.7.3

* CoolBricks1.7.3
	-The same old cobble texture change PLUS red bricks are now retextured to look like grey stone bricks & the brick ingot is recolored to look grey
	-Credit to NFC for the stone brick texture, a slightly modified contrast version of the new vanilla b1.8 stone bricks

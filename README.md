# Beta 1.8.1 – Coxford

Import this zip into Prism Launcher (drag onto the window). Prism downloads b1.8.1 itself.

## Skins
Prism 8+ handles skins for Beta versions on its own (the b1.8.1 version has the `legacyServices` trait).
Make sure it is on: **Settings → Minecraft → Tweaks → "Enable online fixes"** (or per instance under Edit → Settings → Miscellaneous).
No skin mod is needed and none exists for 1.8.1 in this pack.

## Mods (already bundled as jarmods, in this order)
1. `ModLoader B1.8.1.zip`                          – https://mcarchive.net/mods/modloader?gvsn=b1.8.1
2. `SinglePlayerCommands-MC1.8.1V2.12.1.jar`       – https://mcarchive.net/mods/singleplayercommands
3. `TooManyItems2011_09_27_1.8_fix.zip`             – https://mcarchive.net/mods/toomanyitems?gvsn=b1.8.1

WorldEdit.jar from SPC is already in `.minecraft/bin/`. SPC command list: `.minecraft/SPC-readme.txt`.

- The b1.7.3 texture packs (they lack textures for the blocks 1.8 added)
